# ⚡️ Where to Buy the Cheapest White Monster Around You?

**Find the best deal for your favorite energy drink — fast.**

---

### 🚀 What This App Does
- Scrapes data from [kupi.cz](https://www.kupi.cz) to find current sales  
- Displays them in a **mind-blowing interface**  
- Shows a **map with the closest route** to the cheapest White Monster near you  

---

### ⚙️ How to run
1. clone repository
```bash
git clone https://github.com/wiliams12/findMonster
```
2. install dependencies
```bash
python -m pip install -r requirements.txt
```
3. run the script
```bash
python main.py
```
